## Why Runway

- **Because `npx create-expo-app` is 4 minutes you don't have.**
- **Because the idea in your head won't survive a broken Node version.**
- **Because your phone should see your code before your teammates do.**
- **Because "let me just set up the environment" has killed more projects than bad code.**

---

## What you get

| | |
|---|---|
| Write code | Monaco editor, full TypeScript, no config |
| See it instantly | Live phone frame, updates in 600ms |
| Ship to device | QR code → Expo Go → your real phone |
| Share your work | One click exports a runnable `.zip` |

---

## Getting started

```bash
npm install && npm run dev
```

That's it.
